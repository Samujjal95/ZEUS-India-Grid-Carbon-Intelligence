In plain terms: Every time you use electricity in India, some CO₂ is emitted. The mix of coal, gas, hydro, wind, and solar changes every 15 minutes — so the carbon footprint changes too. This product measures that footprint in real time so you can report it accurately and reduce it practically.

3. Formula
// Per 15-min block t: intensity(t) = Σ[gen_fuel(t) × EF_fuel] ──────────── total_generation(t) // × 1000 → g CO₂/kWh
In plain terms: Multiply each fuel's output (MW) by its CO₂ factor, divide by total generation. Result = grams of CO₂ per kWh consumed.
